## Template

Create new ADRs as `NNN-title.md`:

```markdown
# NNN: Title

Status: Proposed | Accepted | Deprecated | Superseded by NNN
Date: 2026-03-22

## Context
What is the problem? What forces are at play?

## Decision
What did we choose?

## Consequences
What becomes easier? What becomes harder?
```
